# 💜 Tisha & Dawis Anniversary Tracker

A personal relationship tracker built with Python, Streamlit, SQLite, and Plotly.

## Features
- 📊 Stats dashboard (days together, countdown to anniversary, weeks/months)
- 🪖 Army service tracker for Dawis
- 💜 Memory journal with categories and emojis
- 🗓️ Timeline of all milestones and memories
- ➕ Add new memories with quick-add suggestions

## Tech Stack
- **Python** — backend logic & calculations
- **Streamlit** — web UI
- **SQLite** — local database
- **Plotly** — interactive charts
- **GitHub** — version control

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Deploy free on [Streamlit Cloud](https://streamlit.io/cloud) by connecting your GitHub repo.
